# 网络知识：Java 后端网络协议与 HTTP 高频面试题

从网络寻址到应用层调用，面向通用 Java 后端岗位整理基础网络协议，并从此前的 35 道题中筛选、合并为 **18 道常见 HTTP 面试题**。内容覆盖 DHCP、ARP/NDP、ICMP、IPv4、IPv6、NAT、HTTP、状态码、会话、连接、缓存、HTTPS、跨域和调用排障。

## 基础网络协议专题

- [从连接 Wi-Fi 到 Java HTTPS 请求：DHCP、ARP、ICMP、IPv4、IPv6 与 NAT](./07-IP寻址与基础网络协议.md)：用一条完整请求链路说明主机如何取得地址、发现下一跳、经过路由与 NAT，并从 Java 异常定位网络层问题。

每道题都按以下顺序回答：

1. **是什么**：先给定义和直接结论。
2. **为什么**：说明设计原因、工作机制和容易混淆的边界。
3. **实际场景怎么用或排查**：给出使用方式、观察证据及处理步骤。

## 复习方法

第一轮按题号阅读，能用一分钟说明每题的定义和原因；第二轮只看标题口述，并补一个使用场景；第三轮用下面三个问题串联知识：

- 一个 HTTPS 接口调用失败，如何区分建连、证书、HTTP 状态和业务错误？
- 浏览器显示跨域错误或旧页面，怎样分别排查 CORS 和缓存？
- 下单请求超时，怎样确认结果、决定重试并避免重复创建？

协议报文示例使用演示数据。Java 客户端的配置项均注明资料版本，实际使用时按项目依赖版本核对；文中的容量与重试方案需要结合实际负载和业务约定。
